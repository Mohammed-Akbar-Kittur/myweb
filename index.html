🏗️ How It Works

git push (your code)
   ↓
GitHub Actions (builds Docker image)
   ↓
Docker Hub (stores image: mohammedakbarkittur/myweb)
   ↓
GitHub Pages (hosts this site live)

PLAN → BUILD → TEST → DEPLOY - 100% Automated & FREE

⚡ Try It Yourself - Copy Paste Commands

1. Pull & Run My Image

docker pull mohammedakbarkittur/myweb:latest
docker run -d -p 8080:80 mohammedakbarkittur/myweb:latest
# Open http://localhost:8080

2. Clone This Repo

git clone https://github.com/Mohammed-Akbar-Kittur/myweb.git
cd myweb
docker build -t myweb .
docker run -p 8080:80 myweb

3. Dockerfile (nginx)

FROM nginx:alpine
COPY index.html /usr/share/nginx/html/index.html
EXPOSE 80

🎁 Make Your Own Website in 2 Minutes

  1. Go to github.com/Mohammed-Akbar-Kittur/myweb → Click Fork
  2. In YOUR fork → Settings → Pages → Branch: main → Save
  3. Edit index.html → Change my name to your name → Commit
  4. Your site: your-username.github.io/myweb/ - LIVE!
